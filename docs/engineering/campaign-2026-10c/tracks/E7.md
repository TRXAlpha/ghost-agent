Every goal has `split="train"` and a unique `goal_id` (not used by `BENCH_GOALS` or
`HELDOUT_GOALS`). Write exactly these eight:

| goal_id | module_file | kind | behaviour |
|---|---|---|---|
| `lru_cache` | `lru.py` | greenfield | `class LRUCache(capacity)` with `get(key, default=None)`, `put(key, value)`, `__len__`; `capacity < 1` → ValueError; least recently *used* (get counts as use) is evicted |
| `csv_report` | `csvreport.py` | greenfield | `summarize(text: str) -> dict` parses CSV text with header `name,amount`; returns `{"count": n, "total": float, "by_name": {name: total}}`; blank lines ignored; non-numeric amount → ValueError naming the line number |
| `bank_parse_fix` | `money.py` | bug-fix | `parse_amount(s) -> int` cents from strings like `"$1,234.50"`, `"-3.5"`, `"7"`; starter bug: drops the minus sign and mishandles one decimal digit (`"3.5"` → 305 instead of 350) |
| `queue_fix` | `boundedqueue.py` | bug-fix | `class BoundedQueue(maxsize)`: `push` raises `OverflowError` when full, `pop` raises `IndexError` when empty, FIFO order, `__len__`; starter bug: `pop` returns LIFO and the full check is off by one |
| `wordwrap` | `wrap.py` | greenfield | `wrap(text, width) -> list[str]`: greedy word wrap, words longer than width are split hard, whitespace runs collapse, `width < 1` → ValueError |
| `json_path_fix` | `jpath.py` | bug-fix | `get_path(obj, path, default=None)` where path like `"a.b.0.c"` walks dicts and lists (numeric parts index lists); starter bug: numeric parts are used as dict keys on lists and missing keys raise instead of returning default |
| `rle` | `rle.py` | greenfield | `encode(s) -> str` (`"aaab"` → `"3a1b"`), `decode(s) -> str`; decode of malformed input (`"a3"`, `"3"`, `""` is valid → `""`) raises ValueError on the malformed ones; round-trip property for strings without digits |
| `stats_fix` | `stats_lite.py` | bug-fix | `mean`, `median`, `mode` (smallest of ties) over a non-empty list; empty list → ValueError; starter bugs: median of even length returns the upper middle, mode returns the largest of ties |

Rules for each goal:
- `goal` text (<= 600 chars) names the module file, every function/class signature, every error
  case, and ends with "Add pytest tests in test_<stem>.py." For bug-fix goals start with
  "The project contains <module_file>, which has bugs." and describe the correct behaviour only
  (do NOT describe the bug).
- `hidden_test`: 3-6 `def test_` functions, imports the module, covers each error case and at least
  one edge case. No network, subprocess or file I/O.
- Bug-fix goals: `starter_files=((module_file, <buggy source>),)`. The buggy source is complete,
  plausible code with exactly the bugs listed above and nothing else broken.
