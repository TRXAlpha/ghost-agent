## E5-1: task model and mechanical validation (review: 2)

```python
@dataclass
class PracticeTask:
    task_id: str            # "pt_" + 12 hex
    goal: str               # <= 600 chars; must name module_file and the function/class signatures
    module_file: str        # ^[a-z][a-z0-9_]{0,30}\.py$
    hidden_test: str        # pytest source, <= 4000 chars
    reference: str          # module source, <= 6000 chars
    mutant: str             # module source, <= 6000 chars, != reference
    topic: str = ""         # <= 80 chars
    source: str = ""        # "goal:<id>" | "concept:<id>" | "weakness:<error_type>" | "manual"
    status: str = "proposed"    # proposed | validated | rejected
    rejection_reason: str = ""
    created_at: float = field(default_factory=time.time)

class CurriculumError(ValueError): ...

def validate_task(task: PracticeTask, timeout: int = 60) -> tuple[bool, str]
```

`validate_task` rules, in this order; the first failure returns `(False, reason)`:

1. Field limits and regexes above; `mutant != reference`.
2. The goal text contains `module_file`.
3. `hidden_test` imports the module (regex `^\s*(from <stem> import|import <stem>)` multiline) and
   defines at least 2 `def test_` functions.
4. Forbidden in hidden_test, reference or mutant (substring check, case-sensitive):
   `subprocess`, `os.system`, `socket`, `requests`, `urllib`, `shutil.rmtree`, `__import__`, `eval(`,
   `exec(`, `open(` (hidden_test only may use `tmp_path`; no `open(`). Reason: `"forbidden construct: <x>"`.
5. In a fresh `tempfile.mkdtemp()`: write `<module_file>` = reference and `test_hidden_practice.py` =
   hidden_test, then run `[sys.executable, "-m", "pytest", "-q", "-p", "no:cacheprovider", "test_hidden_practice.py"]`
   with `cwd` = temp dir, `timeout`, `capture_output`. It must exit 0, else
   `"reference fails its own test: <last 300 chars>"`.
6. Same temp dir, module = mutant: must exit **exactly 1** (tests ran and failed). Exit 0 →
   `"mutant passes: test does not discriminate"`; exit 2–5 → `"mutant errored (exit N): not a behavioural failure"`.
7. Always delete the temp dir (`finally`). A timeout → `"timeout"`.

Return `(True, "")` on success.

**Tests** (`tests/test_curriculum.py`, using real subprocess pytest on tiny tasks): a valid task passes;
a reference that fails is rejected; a mutant that passes is rejected; a mutant with a syntax error is
rejected (exit 2); forbidden constructs; missing import; too few tests; the temp dir is removed.

## E5-2: examiner proposes personal tasks

`Examiner(root: Path, model: str, chat_fn=chat)` with `propose(n: int = 3, focus: str = "") -> list[PracticeTask]`:

- `n` is 1–5. The context is built only from: active goal titles (`GoalStore(root).active()`, ≤ 8),
  learner concept names (`LearnerStore(root).concepts()`, ≤ 10), recent failure `error_type`s from
  `.ghost/trace_learning/last_report.json` if present (≤ 5; read the file shape from trace_learning.py),
  and `focus` (≤ 200 chars). Missing sources are fine.
- The prompt asks for strict JSON
  `{"tasks": [{"goal","module_file","hidden_test","reference","mutant","topic"}]}`. Tell the model the
  rules (pure Python standard library, deterministic, no I/O, 2+ tests, the mutant must differ in
  behaviour in one subtle way, the goal must state signatures). Call
  `chat_fn(model, messages, options={"temperature": 0.7, "num_predict": 4000})`.
  Parse defensively: invalid JSON → `[]`.
- Each task gets an id and `source` (`"goal:<first matched goal id>"` if the topic shares a token with a
  goal title, else `"weakness:<type>"` if a weakness was given, else `"manual"`). Run `validate_task`.
  Store validated tasks as `<root>/.ghost/curriculum/tasks/<task_id>.json` (`atomic_json`). Append
  rejected ones to `<root>/.ghost/curriculum/rejected.jsonl` with the reason. Return all, with statuses.
- `list_tasks(root, status=None)` and `load_task(root, task_id)` are module functions.

**Tests** (scripted chat returning one good task and one with a passing mutant): one validated and stored,
one rejected and logged; invalid JSON gives `[]`; the context contains goal titles (capture messages);
`n` is bounded.
