## Summary
Counts per status (28 rows above): LIVE 7, PARTIAL 19, MISSING 2, TEST-ONLY 0, STUB 0, BLOCKED-EXTERNAL 0.
- LIVE rows: state validation on load, corrupt safety-state fail-safe, interrupted-job recovery, idle-uncertainty conservatism, interactive priority ranking, requirement-fit admission, bounded self-review.
- Top 5 highest-value gaps for the owner:
  1. No schema versioning/migration/backup+rollback for `.ghost` stores (R01-a) — any format change risks losing scheduler/notifications state.
  2. No lease TTL/generation on claimed jobs and no checkpoint field (R01-b): a killed worker's job waits for the next worker start and resumes from zero.
  3. Events lack stable IDs, correlation/causation, sensitivity, and any subscription/cursor/retry/failed-event queue (R01-c) — the spec's event contract is mostly absent.
  4. No external-action receipt reconciliation or uncertain-result record (R01-d): in-flight external actions at crash are simply lost.
  5. Resource governance is two metrics deep: no GPU/network/cost ceilings, no reservation reclaim, no mid-job pause on owner return, no service install controls (R12-a/b).
- External blockers: none in this area — all R01/R12 gaps are local engineering. (Non-Windows idle detection depends on OS APIs, not credentials; Windows-only coverage is a platform scope decision, not blocked.)
