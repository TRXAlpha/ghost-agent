- Counts per status (27 rows: R03 10, S06 11, S07 6):

  - PARTIAL: 21
  - TEST-ONLY (component-level): 1 (MorningDigest store-based digest — class fully tested, instantiated only by tests; the overnight markdown digest is LIVE)
  - STUB: 0
  - MISSING (component-level): standing idle-preference persistence (S06)
  - BLOCKED-EXTERNAL: 0 (all gaps are local engineering; no credentials/hardware required)
- Top 5 highest-value gaps for the owner:
  1. Quiet-hours notification suppression is not wired: AttentionManager.deliverable (runtime.py:453) has no production caller, so overnight notifications are not actually withheld — the central S06 notification promise only half-works.
  2. Paid-inference budget has no production caller: DurableInferenceBudget (spend.py:45) + chat() reservation discipline (models/chat.py:48-78) is never used by proactive/overnight/daemon, so idle-time inference is unbounded by call limits (S06).
  3. Initiative ranking/selection is heuristic, not the specified transparent multi-factor ranking: no composite score, no ranking reasons, no tuning from outcomes, benefit enum never consulted before auto-queue (R03).
  4. Opportunity records lack the required structured fields (trigger IDs, deadline, review interval, alternatives, risks, uncertainty), and rejected ideas are only hash-suppressed — reworded ideas bypass suppression (R03/S07).
  5. No persisted standing idle-work policy and no in-job checkpointing: loops must be launched manually each session, and interrupted jobs restart from scratch (S06).
- External blockers with exact prerequisite: none. Every gap above is closable locally; the only platform limitation is idle detection (GetLastInputInfo) being Windows-only (proactive.py:137), which makes proactive work structurally deferred on other hosts but is not an external credential/hardware blocker.
